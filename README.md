# 성적 CSV 검증 프로그램

## ① 무엇을 하나요 (What)
성적 CSV 파일을 읽어 유효한 점수(0~100점 정수)만 골라내고, 형식이 잘못된 줄은 사유와 함께 별도로 기록합니다.

## ② 왜 만들었나요 (Why)
실제 성적 파일에는 빈 줄, 누락된 이름이나 점수, 0~100 범위를 벗어난 점수가 섞여 있어 그대로 처리하면 프로그램이 죽거나 잘못된 통계가 계산되기 때문입니다. 또한 동명이인을 임의로 삭제하지 않고 보존하기 위해 검증과 기록 기능을 분리했습니다.
